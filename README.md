## Опис проєкту

SkyBook — вебзастосунок для пошуку, перегляду та бронювання авіаквитків. Користувачі можуть шукати авіарейси за напрямком, переглядати інформацію про рейси та оформлювати бронювання.

## Основні можливості

- Пошук авіарейсів за містом відправлення та прибуття.
- Перегляд доступних авіарейсів.
- Перегляд інформації про конкретний рейс.
- Бронювання авіаквитків.
- Введення та перевірка даних пасажира.

## Сутності проєкту

- Airport — аеропорт.
- Flight — авіарейс.
- Passenger — пасажир.
- Ticket — квиток.

## Стек технологій

HTML5, CSS3, JavaScript, Git, GitHub.  
Подальший технологічний стек визначатиметься в процесі розробки.
