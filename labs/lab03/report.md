### 3.3. Підключення CSS

У роботі продемонстровано три способи підключення стилів.

**1. Вбудований стиль (Inline CSS)**

Стиль задається безпосередньо в атрибуті `style` HTML-елемента.

```html
<blockquote style="font-style: italic;">
```

Такий спосіб підходить для поодиноких винятків, але не рекомендується для оформлення великих сторінок.

**2. Внутрішня таблиця стилів (Internal CSS)**

Стилі розміщуються всередині елемента `<style>` у документі HTML.

```html
<style>
    .flight-intro {
        border-left: 4px solid #f0a83c;
        padding-left: 16px;
    }
</style>
```

Цей спосіб зручний для стилів, які використовуються лише на одній сторінці.

**3. Зовнішня таблиця стилів (External CSS)**

Для підключення зовнішнього файлу використовується елемент:

```html
<link rel="stylesheet" href="../css/style.css">
```

Зовнішній CSS є основним способом оформлення проєкту, оскільки дозволяє використовувати спільні стилі на різних сторінках і спрощує їх підтримку.

Для автоматичної зміни кількості колонок карток використовується CSS Grid із функцією `repeat()` та `minmax()`.

Завдяки цьому браузер самостійно визначає кількість колонок залежно від доступної ширини контейнера без необхідності створювати окремі медіазапити для кожної кількості карток.

## 5. Контрольні запитання

**1. Які існують способи підключення таблиць стилів і в чому переваги зовнішніх файлів?**

Існує три основні способи підключення CSS: вбудований, внутрішній та зовнішній.

Вбудований стиль задається через атрибут `style` конкретного HTML-елемента. Внутрішній стиль розміщується в елементі `<style>` усередині HTML-документа. Зовнішній стиль зберігається в окремому CSS-файлі та підключається через `<link>`.

Перевага зовнішніх файлів полягає в тому, що один файл стилів можна використовувати на багатьох сторінках. Це спрощує редагування, підтримку та повторне використання оформлення.

**2. Як обчислюється специфічність селектора? Наведіть приклад розв’язання конфлікту правил.**

Специфічність визначає пріоритет CSS-селектора. Вона обчислюється за кількістю ідентифікаторів, класів, атрибутів, псевдокласів та селекторів елементів.

Наприклад:

```css
p {
    color: black;
}

.notice {
    color: blue;
}
```

Селектор `p` має специфічність `0,0,0,1`, а `.notice` — `0,0,1,0`. Тому для абзацу з класом `notice` застосовується синій колір.

**3. Чому застосування !important вважається поганою практикою?**

`!important` примусово підвищує пріоритет CSS-властивості. Його надмірне використання ускладнює розуміння каскаду та подальше редагування стилів. Через це можуть виникати конфлікти, для вирішення яких доводиться додавати нові правила з `!important`.

Краще правильно організовувати селектори та структуру CSS.

**4. Опишіть блокову модель. Чим відрізняються content-box і border-box?**

Блокова модель CSS складається з чотирьох частин: content, padding, border і margin.

- `content` — вміст елемента.
- `padding` — внутрішній відступ.
- `border` — межа елемента.
- `margin` — зовнішній відступ.

За `content-box` задана ширина стосується лише вмісту, а внутрішні відступи та межі додаються до неї.

За `border-box` задана ширина вже включає вміст, внутрішні відступи та межі. Це полегшує розрахунок розмірів елементів.

**5. У чому різниця між Flexbox і CSS Grid? Для яких задач застосовують кожен модуль?**

Flexbox призначений для одновимірного компонування елементів — у рядок або колонку. Його зручно використовувати для навігаційних меню, кнопок і вирівнювання елементів.

CSS Grid призначений для двовимірного компонування — одночасної роботи з рядками та колонками. Він підходить для створення загального макета сторінки, сіток карток і бічних панелей.

**6. Поясніть призначення властивостей justify-content, align-items і gap.**

- `justify-content` вирівнює елементи вздовж головної осі контейнера.
- `align-items` вирівнює елементи вздовж поперечної осі.
- `gap` задає проміжки між елементами або рядками та колонками сітки.

Ці властивості використовуються для керування розташуванням елементів у Flexbox і Grid.

**7. Що таке псевдоклас і псевдоелемент? Наведіть по три приклади.**

Псевдоклас визначає особливий стан HTML-елемента або його положення в структурі документа.

Приклади:
- `:hover` — наведення курсора.
- `:focus-visible` — видимий стан фокуса.
- `:nth-child(2n)` — вибір парних дочірніх елементів.

Псевдоелемент дозволяє стилізувати певну частину елемента або створювати додатковий віртуальний елемент.

Приклади:
- `::before` — додає вміст перед елементом.
- `::after` — додає вміст після елемента.
- `::first-letter` — стилізує першу літеру тексту.

**8. Як працює функція repeat(auto-fill, minmax(240px, 1fr))?**

`repeat()` автоматично повторює визначення колонок. `auto-fill` намагається розмістити максимально можливу кількість колонок у доступному просторі. `minmax(240px, 1fr)` задає мінімальну ширину колонки 240 px, а максимальну — одну доступну частку вільного простору.

Таким чином, кількість колонок змінюється залежно від ширини контейнера без додаткових медіазапитів.

**9. Які одиниці вимірювання є відносними та у яких випадках їх застосовують?**

До відносних одиниць належать:
- `%` — відносно розміру батьківського елемента.
- `em` — відносно розміру шрифту поточного контексту.
- `rem` — відносно розміру шрифту кореневого елемента.
- `vw` — відносно ширини вікна браузера.
- `vh` — відносно висоти вікна браузера.

Їх використовують для створення гнучких і адаптивних інтерфейсів.

**10. Чим відрізняються значення властивості position: relative, absolute, fixed і sticky?**

- `relative` — елемент залишається у звичайному потоці документа, але може зміщуватися відносно свого початкового положення.
- `absolute` — елемент вилучається зі звичайного потоку та позиціонується відносно найближчого позиціонованого предка.
- `fixed` — елемент позиціонується відносно вікна браузера та залишається на місці під час прокручування.
- `sticky` — елемент поводиться як звичайний до досягнення заданої межі прокручування, після чого фіксується в межах свого контейнера.

**11. Для чого призначений метатег viewport?**

Метатег viewport задає параметри відображення вебсторінки на мобільних пристроях. Він дозволяє браузеру використовувати реальну ширину екрана пристрою та правильно масштабувати сторінку.

Приклад:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Без цього метатега сторінка може відображатися на мобільному пристрої зі зменшеним масштабом, що погіршує зручність користування.
