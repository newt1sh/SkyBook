# REST API проєкту SkyBook

## Призначення

REST API призначений для роботи з каталогом авіарейсів, аеропортами, пасажирами та бронюванням квитків.

## Основні кінцеві точки

| № | Метод | URL | Призначення |
|---|---|---|---|
| 1 | GET | `/airports` | Отримати список аеропортів |
| 2 | GET | `/airports/:id` | Отримати інформацію про аеропорт |
| 3 | GET | `/flights` | Знайти рейси за параметрами |
| 4 | GET | `/flights/:id` | Отримати інформацію про рейс |
| 5 | GET | `/flights/:id/tickets` | Переглянути квитки на рейс |
| 6 | POST | `/tickets` | Створити бронювання квитка |
| 7 | GET | `/tickets/:id` | Отримати інформацію про квиток |
| 8 | PATCH | `/tickets/:id` | Частково змінити дані квитка |
| 9 | DELETE | `/tickets/:id` | Скасувати бронювання |
| 10 | GET | `/passengers/:id/tickets` | Отримати квитки пасажира |

## Параметри пошуку рейсів

Для `GET /flights` передбачені такі query-параметри:

- `from` — код аеропорту відправлення;
- `to` — код аеропорту прибуття;
- `date` — дата рейсу;
- `maxPrice` — максимальна ціна квитка;
- `sort` — сортування результатів;
- `page` — номер сторінки результатів.

Приклад запиту:

`GET /flights?from=KBP&to=JFK&date=2026-12-01&maxPrice=500`

## Приклад створення бронювання

Запит:

`POST /tickets`

Тіло запиту:

```json
{
  "flightId": 15,
  "passengerId": 8,
  "seatNumber": "12A"
}
```

Приклад успішної відповіді зі статусом `201 Created`:

```json
{
  "id": 102,
  "flightId": 15,
  "passengerId": 8,
  "seatNumber": "12A",
  "status": "booked"
}
```

## Формат помилки

Приклад відповіді у разі помилки валідації:

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Некоректні дані бронювання"
  }
}
```

## Загальні правила API

- GET використовується для отримання даних.
- POST використовується для створення нових записів.
- PATCH використовується для часткового оновлення даних.
- DELETE використовується для видалення або скасування записів.
- Ідентифікатори ресурсів передаються в URL.
- Параметри фільтрації та пошуку передаються через query-параметри.
- Дані запитів і відповідей передаються у форматі JSON.
